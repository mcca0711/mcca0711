## Selected Projects

### Bird Observation Explorer

Interactive geospatial explorer for sampled eBird observations across Canada and the United States.

Built with Vue, TypeScript, MapLibre, Deck.gl, D3, GeoPandas, GeoParquet, and DuckDB WASM.

- Interactive density and point-based mapping
- Spatial analysis with GeoPandas
- Browser-side querying with DuckDB WASM
- Seasonal visualization and filtering
- Automated data acquisition, validation, testing, and CI

[Live Demo](https://mcca0711.github.io/bird-observation-explorer/)  
[GitHub](https://github.com/mcca0711/bird-observation-explorer)

### Renewable Energy Data Explorer

Full-stack environmental data application for exploring 48-hour renewable-energy forecasts through interactive charts, maps, KPIs, and persisted run history.

Built with Next.js, React, TypeScript, Recharts, Leaflet, FastAPI, PostgreSQL, and Docker.

[GitHub](https://github.com/mcca0711/renewable-energy-data-explorer)

### Solar Panel Optimizer

Early geospatial prototype for searching locations and visualizing a simple solar-outlook indicator on an interactive Leaflet map.

Built with Flask, JavaScript, Leaflet, and OpenStreetMap.

[GitHub](https://github.com/mcca0711/solar-panel-optimizer)

### Berly

Desktop AI compliance documentation product built with React and TypeScript, including automated testing, document export, licensing, payments, and release workflows.

[Website](https://berly.app)
